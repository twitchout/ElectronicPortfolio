KirJ_Unit2_Ex3 — RESTful AJAX-JSON Web Service DYNAMIC

CIS 266 — Web Services  ·  Spring 2026

✓ COMPLETE

A full RESTful web service architecture built with PHP and MySQL. The Service Provider exposes two JSON endpoints: one that returns a single course record by primary key (KirJ_Students_API.php) and one that returns all records (KirJ_Students_DisplayAll_API.php). Both use an OOP data-access class (KirJ_Students_Access) with prepared statements (PDO-style MySQLi) against the students / KirJ_courses MySQL table. The Service Client consumes those endpoints via AJAX/jQuery, rendering results dynamically via innerHTML — no page reload. Includes a standalone OOP tester and a raw API tester page.

── UNIT 3 — WCF CALCULATOR ──────────────────────────

WCF Calculator Web Service STATIC · .NET

CIS 266 — Web Services  ·  Unit 3

✓ COMPLETE

A Windows Communication Foundation (WCF) SOAP-based web service built with C# and .NET. The solution consists of a CalculatorService project that implements a [ServiceContract] interface exposing Add, Subtract, Multiply, and Divide operations, and a CalculatorClient project that consumes the service. Demonstrates the SOAP/WSDL service model as a contrast to the RESTful JSON approach used elsewhere in CIS 266.

C# .NET WCF SOAP WSDL ServiceContract OperationContract Visual Studio
ICalculatorService.cs 
[ServiceContract]
public interface ICalculatorService
{
    [OperationContract]
    double Add(double a, double b);

    [OperationContract]
    double Subtract(double a, double b);

    [OperationContract]
    double Multiply(double a, double b);

    [OperationContract]
    double Divide(double a, double b);
}
