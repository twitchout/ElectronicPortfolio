Drive — Fleet Management System

Personal / Professional Project  ·  2025–2026

⚡ IN PROGRESS

A comprehensive, production-grade fleet management platform built for a real-world client. Drive tracks vehicles, drivers, and daily operations across three integrated applications: a RESTful ASP.NET Core 8 backend API, a React/Vite admin web dashboard, and a cross-platform Flutter mobile app for drivers. Drivers use the mobile app to clock in/out, submit daily vehicle checklogs, and track location during shifts. Fleet managers use the admin dashboard for full CRUD operations, reporting, and oversight. The system uses JWT authentication, Entity Framework Core with SQL Server, and is structured around a clean layered architecture (Drive.Core → Drive.Infrastructure → Drive.Api). Currently in active development for a prospective business client.

C# / .NET 8 ASP.NET Core Entity Framework Core SQL Server REST API JWT Auth React Vite TypeScript Flutter Dart Swagger / OpenAPI

── STAGE 04 ──────────────────────────────────────────

Secure Banking Application

CIS 225 — Secure Programming  ·  2025–2026

✓ COMPLETE

A full-stack secure banking web application built with Node.js and Express, demonstrating enterprise-grade security practices from CIS 225. The app runs over HTTPS with self-signed certificates and enforces a strict Content Security Policy via Helmet. Security features include bcrypt password hashing, brute-force protection with rate limiting (5 login attempts per 15 minutes), HTTP Parameter Pollution prevention, and server-side input validation on every endpoint via express-validator. User sessions are managed securely with httpOnly, sameSite, and secure cookie flags. The system supports both user and admin roles, with a full audit log tracking all authentication events and transactions. Data is persisted in SQLite via better-sqlite3, with CRUD operations for accounts, deposits, withdrawals, and transfers.

Node.js Express SQLite bcrypt Helmet (CSP / HSTS) Rate Limiting HTTPS / TLS express-validator Session Auth Audit Logging Role-Based Access JavaScript
